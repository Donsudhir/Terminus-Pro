## Update protocol

After each meaningful task event:

1. Add or update nodes for new facts, failures, decisions, sources, evidence, and patterns.
2. Add edges showing causality, governance, support, conflict, prevention, or supersession.
3. Never delete historical nodes. Mark them superseded or rejected.
4. Link every durable decision to an ADR.
5. Link every claimed PASS to command evidence.
6. Promote repeated failure patterns into reusable rules only after evidence from multiple instances.
