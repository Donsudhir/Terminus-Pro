# Audit Report Schema

The audit report is UTF-8 JSON with a trailing newline. Top-level keys:

- `status`: always the string `complete`.
- `cases`: array of per-case objects (sorted by `case_id`).
- `digest`: SHA-256 over the canonical serialization of `cases` (see below).

Each case object has exactly these keys:

- `case_id` (string): directory name of the case.
- `row_count` (integer): number of live rows contributing to the sum.
- `sum_amount` (integer): sum of live amounts.
- `pages_total` (integer): number of pages in the store.
- `pages_read` (integer): number of pages actually read during the audit.
- `path` (string): absolute path to the case's `data.store`.
- `skipping` (boolean): whether the fast path skipped any pages.

Canonical serialization for the digest:

- Serialize `cases` as compact JSON (no spaces), keys in the order above.
- Encode as UTF-8 and hash with SHA-256; store the hex digest.
