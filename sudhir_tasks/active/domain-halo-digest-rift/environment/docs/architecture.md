# Architecture notes

The laboratory binary under `/app/bin/partlab` stitches compiled native
kernels and a Rust host into one offline driver. Native units own fringe
braid helpers, local-norm banners, and sample folding. The host owns stage
shelf wiring and report assembly.

Runtime defaults live in `/app/conf/runtime.conf`. Bundled families live under
`/app/data/`. Fixture traces under `/app/fixtures/` are observational only and
do not encode graded answers. Build with `/app/tools/build_all.sh` or `make`
from `/app`.
