The geometry lab under `/app` rebuilds a tetrahedral connectivity report from bundled point-cloud batches. Ordinary batches look mostly fine, but equivalent batches that are only shifted or uniformly rescaled can emit different canonical cell sets. Near-flat and nearly spherical boundary cases also leave inverted cells, broken neighbor relations, or a connectivity ledger that disagrees with the audit summary. Cancellation-heavy floating sums are another weak spot: the fast numeric path has to stay conservative — when a sum is dominated by cancellation it must escalate to exact refinement instead of certifying a firm sign opposite the true exact sign — while well-conditioned sums still have to certify their true sign on the fast path.

Correct the scientific pipeline so `/app/output/geometry_report.json` is deterministic and geometrically consistent for every bundled batch and its equivalent transformed variants. Rebuild through the project scripts, including the strict alternate build, and run `/app/bin/geomlab`. Default paths come from `/app/config/runtime.conf`; `GEOMLAB_INPUT` and `GEOMLAB_OUTPUT` override them for laboratory runs. Diagnosis helpers on the same binary: `/app/bin/geomlab --inspect-series <exact_sign> <terms...>` probes the fast numeric decision on a term list, and `/app/bin/geomlab --inspect-status <raw>` probes how a raw refinement code is mapped into control flow.

The report is compact JSON with `schema_version`, `batches` ordered lexicographically by family then variant (the bundled corpus contributes 9 batches once every family variant is present), and a sixteen-character lowercase hex `digest`. Each batch keeps identity (`family`, `variant`, `point_ids`), canonical cells as sorted rows of point identities with consistent positive handedness, adjacency, orientation summary, local validity summary, and topology counts. Repeated clean runs of the same inputs must be byte-identical. Malformed input must exit nonzero without writing a partial report. Do not replace the bundled inputs or hand-write the report; the checks regenerate it through the compiled pipeline.
