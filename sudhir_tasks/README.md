# Sudhir Tasks

Canonical editable task source lives under `active/<task-name>/`. Rejected or superseded task sources move to `archived/<task-name>/` only after an ADR or task decision records why.

Do not maintain mutable copies under upstream task folders. Compatibility staging must be generated from canonical source and never edited directly.

Before creating a task directory, require:

1. idea record;
2. category decision;
3. uniqueness research;
4. Step 2a GO;
5. accepted authoring spec and construction commitments.
