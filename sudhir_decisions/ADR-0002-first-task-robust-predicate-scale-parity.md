# ADR-0002: First Task Is Robust Predicate Scale Parity

- Status: Accepted for Step 2a validation
- Date: 2026-07-18
- Task ID: TASK-RPSP-001

## Context

The task corpus is saturated with scheduling, dispatch, replay, reconciliation, embeddings, ANN, and generic audit patterns. Research identified robust computational geometry and certified numerical predicates as a largely unoccupied area with strong production value and deterministic mathematical invariants.

## Decision

The first task developed under the new lifecycle is `robust-predicate-scale-parity`.

- Primary category: `scientific-computing`
- Planned languages: C, Rust, and Fortran
- Environment: single-container, offline, deterministic
- Core domain: robust determinant predicates and topology consistency under near-degenerate geometry and affine-equivalent inputs

The task is not categorized as debugging or software engineering. Its primary activity is restoring scientifically valid geometric computation across numerical and language boundaries.

## Required Step 2a evidence

- At least three non-trivial discoveries that are absent from the public instruction.
- Three plausible fix topologies, each spanning at least three locations.
- A symptoms-only public contract.
- Property-based verification using exact predicate signs, local Delaunay validity, orientation consistency, affine invariance, and topology checks.
- Evidence that no existing archived task has the same mathematical or structural core.

## Constraints

No implementation files are created until the repository baseline can run Step 2a reliably and the idea receives GO. The language mix must remain necessary rather than decorative. If the authoring design cannot be bounded to an expert-hours repair task, this ADR must be superseded rather than forcing construction.
